# ClipboardPro · 桌面剪贴板工具

Windows 常驻剪贴板历史工具，保存**文本 + 图片**，默认 **300 条**。纯本地、无网络、无遥测。

**当前版本：0.5.3** · Windows 10/11 64 位 · 自带 .NET 运行时，双击即用

---

## 主要功能

- **文本 + 图片**都记，默认 300 条历史，条数和磁盘双闸门自动淘汰旧记录
- **全局热键** `Ctrl+Shift+V` 呼出历史窗口（热键可任意修改）
- **默认只复制不自动粘贴**，选中后自己 `Ctrl+V`；想选中即粘贴可在设置里开
- **弹窗可拖动、可缩放**，位置和大小都会记住
- **图片双击看大图**，滚轮缩放、拖动平移
- **图片可命名**（不强制），名字参与搜索，且不允许重名
- **每条记录带日期时间**，列表排序稳定，选中不跳位
- **多选**（Ctrl / Shift 或右键「多选」）：多条文本可批量复制（空行分段），图片只能单张复制，文本与图片都可批量删除 / 固定
- **右键菜单**：复制 / 多选 / 全选图片 / 全选文本 / 清空选择 / 固定 / 重命名 / 删除
- **窗口可与其它软件共存**（可切换置顶），带最小化/关闭按钮
- **托盘图标常驻**，随时能看到程序在不在运行
- **数据目录可自定义**（支持迁移历史数据）
- **自动更新**：启动后自动检查新版本，弹窗提示更新内容，一键下载安装（支持断点续传）

## 快速上手

1. 下载 `ClipboardPro-win64.zip`，解压得到 `ClipboardPro.exe`
2. 双击运行（第一次启动稍慢 1~2 秒，之后正常）
3. 托盘出现图标 = 已在记录。复制任何东西都会自动存进历史
4. 按 `Ctrl+Shift+V` 弹出历史列表，选中后按 `Enter` 复制
5. 需要改快捷键、数据目录等：点历史窗口右上角的**齿轮**进设置

## 快捷键（全部可自定义）

| 操作 | 作用 |
| --- | --- |
| `Ctrl+Shift+V` | 打开 / 关闭历史窗口 |
| `↑` `↓` | 选择条目 |
| `Enter` | 复制到剪贴板 |
| `Ctrl+Enter` | 反向操作（复制并粘贴 / 仅复制） |
| `Del` | 删除选中条目（多选时批量删除，会确认） |
| `Ctrl+P` | 固定 / 取消固定（多选时批量） |
| `Esc` | 收起窗口（多选时先取消选择） |
| `F2` | 给图片起名字 |
| `双击` | 文本复制；图片打开大图预览 |
| `Ctrl+单击` | 多选加选 / 取消 |
| `Shift+单击` | 从当前条连选 |
| `右键` | 弹出菜单：复制、多选、全选、固定、重命名、删除 |

### 多选规则

| 选中内容 | 复制 | 删除 | 固定 |
| --- | --- | --- | --- |
| 多条文本 | ✅ 每条之间空一行拼起来 | ✅ 批量 | ✅ 批量 |
| 多张图片 | ❌ 图片只能单张复制 | ✅ 批量 | ✅ 批量 |
| 文本 + 图片混选 | ❌ 不能混合复制 | ✅ 批量 | ✅ 批量 |

> 想要“勾选式”多选：右键 →「多选」，每行左侧会出现勾选框，单击即勾选。

## 自动更新

- 程序启动后自动检查新版本（24 小时内最多一次），清单托管在 **Gitee**（国内访问快）
- 有更新时弹窗显示**版本号、更新内容、文件大小**，点「立即更新」自动下载、校验、安装、重启
- 下载支持**断点续传**，断线后从已下载位置继续；窗口里会显示速度与剩余时间
- 检查失败不会锁死一整天：失败不记时间，15 分钟后自动再试
- 不想更新点「稍后」，下次启动会再提醒；设置 → 通用里可关闭自动检查

## 隐私说明

- 所有记录只存在**你自己电脑**上（SQLite 数据库），不上传、不联网
- 唯一的网络访问是**自动更新检查**（读取 Gitee 上的版本清单），可在设置里关掉
- 剪贴板里的密码、敏感内容一样会被记录，介意的话可以在设置里关掉对特定软件的监听
